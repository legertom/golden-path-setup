# 🔥 Campfire 2026 · Builder Setup

Hi Builder! Thank you for joining the Campfire hackathon. We're so excited to build with you! 🎉

Before Campfire, you'll get your laptop ready with Claude's help. Claude does the technical work and explains each step as you go, so you don't need any coding experience. It takes about an hour, and some of that is waiting while things install.

By the end, you'll have Claude Code and **VS Code** (a free app for seeing your project's files) on your Mac, plus a live team web page. The page shows everyone's names and roles and a checklist of everything you set up.

📅 **Due by 5pm on Friday, November 6.** The last step is sending Tom and Katie the link to your team's live page.

## Step 1: Download the setup file

1. Click **[campfire-builder-setup.md](campfire-builder-setup.md)** to open it.
2. Near the top right of the file, click the **download** button (⬇). When you hover over it, it says "Download raw file".
3. The file lands in your **Downloads** folder.

## Step 2: Give it to Claude

**Already using Claude Code?** That means the **Code** tab in the Claude desktop app, the Claude Code extension in VS Code, or the Terminal.
1. Open Claude Code.
2. Copy this line, paste it into the message box and press **Return**:

   ```
   Read ~/Downloads/campfire-builder-setup.md and walk me through the setup.
   ```

   You can also drag the file from your Downloads folder into the message box instead.

**Never used Claude Code, or not sure?** No problem!
1. Open the Claude app, or go to [claude.ai](https://claude.ai), and start a new chat.
2. Drag the file from your Downloads folder into the message box (or click **+** to attach it), then press **Return**.
3. Claude will welcome you and help you open Claude Code. You'll finish the setup there.

That's it. Claude takes it from here!

## Good to know

- **Along the way, you'll be asked to OK the installation of a few tools** (like git and VS Code). That's expected, so go ahead and accept.
- **Claude Code asks permission before it does things on your Mac.** For this setup it's fine to click **Allow**.
- **Never paste passwords into the chat.** Claude will never ask you to.
- **Questions?** Ask Claude. If Claude can't answer, ask Tom or Katie.
